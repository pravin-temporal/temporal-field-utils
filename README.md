# Temporal Field Utils

> ⚠️ **Not an official Temporal repository.** This is a personal collection of
> utility scripts, maintained in my individual capacity as a Platform
> Architect. It is **not supported, endorsed, or maintained by Temporal
> Technologies, Inc.** Use at your own risk.

Small, practical scripts for working with Temporal day to day, built from
real friction points in customer-facing field work.

## Tools

| Tool | What it does |
|---|---|
| [`env/env-switch.sh`](./env) | Switch your shell between Temporal profiles (local dev server, Cloud namespaces, …) with one command. |

Folders are grouped by purpose. Planned: `observability/`, `cost/`, `diagnostics/`.
